# 环形路线生成器 · 跑步 / 骑行
在地图上选一个出发点（同时也是终点），输入想跑的公里数，自动生成 3 条**从起点出发、绕一圈回到起点**的环形路线，距离误差控制在 ±10% 以内。例如选自己家、输入 50km，就会得到 3 条从家出发又回到家的 50km 环线。

纯前端静态页面，无需后端、无需构建、无需安装依赖。

## 一个故事
在2026年的大年初五，本人心血来潮，觉得骑自行车返回老家。路程其实并不长，最后只骑了70km，但是由于本人能力实在有限，回到老家后已没有能力把车骑回家去……
在几个月后，于是想到：是否有简单的规划方式规划路线，使我骑车可以完成预计的里程目标，并且在完成后正正好回到原点，于是减少了调度搬车的麻烦呢？

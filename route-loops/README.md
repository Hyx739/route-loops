# 环形路线生成器 · 跑步 / 骑行

在地图上选一个出发点（同时也是终点），输入想跑的公里数，自动生成 3 条**从起点出发、绕一圈回到起点**的环形路线，距离误差控制在 ±10% 以内。例如选自己家、输入 50km，就会得到 3 条从家出发又回到家的 50km 环线。

纯前端静态页面，无需后端、无需构建、无需安装依赖。

## 使用方法

**方式一（最简单）**：直接双击 `index.html`，用 Chrome / Edge 打开。

**方式二（推荐，定位功能需要）**：在本目录下起一个本地服务，然后访问 `http://localhost:8000`：

```bash
cd route-loops
python3 -m http.server 8000
```

> 只有 localhost 或 https 页面浏览器才允许获取定位。用方式一打开时，「定位」按钮会提示失败，手动点地图选点不受影响。

操作流程：

1. 选运动类型（跑步 / 骑行）——两者的距离范围与速度估算不同
2. 在地图上点击选择出发点（也可用「定位」按钮定位到当前位置）
3. 输入或拖动目标距离
4. 点「生成路线」，等待 5~15 秒（原因见下方「为什么这么慢」）
5. 点击卡片或地图上的路线可高亮对比，再点一次取消

## 更换高德 Key

`config.js` 里目前是项目自带的一个 Key，**建议换成自己的**（免费）：

1. 打开 <https://console.amap.com/dev/key/app>，注册并完成个人开发者实名认证
2. 「应用管理 → 我的应用 → 创建新应用」
3. 为应用**添加 Key**，服务平台必须选 **「Web服务」**（不是「Web端(JS API)」，选错了会报 `USERKEY_PLAT_NOMATCH`）
4. 把生成的 Key 填进 `config.js`：

```js
window.AMAP_KEY = '你的Key';
```

个人开发者有免费额度，日常使用足够（实测个人 Key 的 QPS 限制约 3 次/秒，日配额在万次量级）。

## 为什么生成要等 5~15 秒

- 高德没有「环形路线」接口，环线是拆成 4~6 段独立的 A→B 路线规划拼接出来的；每条候选路线少则 4 次请求，距离不合适要重算时最多 18 次
- 个人 Key 有**约 3 次/秒**的 QPS 限制，程序里所有请求串行排队（间隔 350ms），超限会自动退避重试
- 距离不合适的候选会自动调整半径重算，所以实际请求数不固定

## 已知局限

- **无海拔/爬升数据**：高德路径规划接口不返回高程信息
- **路线是公路网环线**，不专门区分绿道或骑行专用道（高德骑行规划本身会倾向选择适合骑行的道路）
- 城区路网密集处更容易凑准距离；过于空旷或路网稀疏的区域可能只生成 1~2 条，会有提示可再点一次换一批
- **Key 明文写在 `config.js` 中**：自己本地用没问题；若要把这个项目公开分享（传到 GitHub 等），请先换成自己的 Key，或把 Key 从代码里移除

### 算法要点

把起点 S 作为正 4/5/6 边形的一个顶点，其余顶点分布在过 S 的外接圆上，路线沿多边形的边走一圈，天然闭合。首个途经点的方位角由圆心方位反解得到，保证「起点出发方向」与候选的扇区分布一致（否则去重会把看起来相同的路线当成不同路线）。

实际道路距离与直线距离之比（绕行系数）按运动类型实测标定（骑行 ≈1.44、跑步 ≈1.5 且非线性），按 `距离 ∝ 半径^p` 迭代校正半径：同一候选量到两次「半径→距离」实测点后，用 log-log 割线估计局部指数 p 代替固定指数，收敛更快也更省请求。每条候选实测出的绕行比还会反馈修正后续候选的初始半径。候选按出发方位角去重（相差 <30° 视为相似）。

### 测试

```bash
node test/geometry.test.mjs  # 环线几何不变量（纯计算，毫秒级，无需网络）
node test/loopgen.test.mjs   # 算法（调真实高德 API）：3 条环线、偏差、闭合度、方位分散
node test/errors.test.mjs    # 异常路径：Key 无效/未配置、未知类型、未选起点等提示
node test/e2e.mjs            # 浏览器端到端（无头 Chrome）：需先起 8000 端口服务
```

`loopgen.test.mjs` 与 `errors.test.mjs` 直接测生产代码（`js/amap.js`、`js/loopgen.js`），只把浏览器的 JSONP 传输层换成 Node 的 `fetch`，其余逻辑（限速队列、解析、迭代、去重）完全一致；`CASE=run`（或 `ride20` / `ride50`）可只跑单个用例。`e2e.mjs` 用无头 Chrome + DevTools 协议跑完整交互（含 400px 窄屏下的生成与遮挡检查），并输出截图到 `/tmp/route-loops-desktop.png` 和 `/tmp/route-loops-mobile.png`。
